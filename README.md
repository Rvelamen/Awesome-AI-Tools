## 👥 贡献指南

所有条目统一维护在 [`data.json`](./data.json) 中（README 不再逐个列出工具），网站会在合并 PR 后自动构建部署。欢迎通过以下方式参与共建：

1. 提交 Pull Request，在 `data.json` 中添加新工具
2. 完善现有条目的描述与链接
3. 建议新的分类维度

**条目格式要求**：
```json
{
    "url": "",
    "title": "",
    "type": "",
    "description": "",
    "image": "",
    "category": [
    ],
    "id": ""	// uuid
}
```

**注意事项**：
- `url` 请使用干净的官方链接，不要带 `utm` 等追踪参数，提交前请确认可正常访问
- 描述保持客观，避免无法核实的宣传性表述
- `id` 必须是目录中未使用过的 UUID
- `category` 请优先使用已有的分类名称（见上方分类概览）
- 提交前运行 `jq empty data.json` 确认 JSON 合法
