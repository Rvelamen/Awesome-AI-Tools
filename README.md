## Contributing

All entries live in [`data.json`](./data.json); the READMEs show a curated subset per category, and the website rebuilds automatically after PRs are merged. Contributions are welcome:

1. Open a Pull Request adding new tools to `data.json`
2. Improve descriptions and links of existing entries
3. Suggest new categories

**Entry format**:
```json
{
    "url": "",
    "title": "",
    "type": "",
    "description": "",
    "image": "",
    "category": [
    ],
    "kind": "",	// optional: "project" for open-source projects; omit for tools
    "id": ""	// uuid
}
```

**Notes**:
- `url` must be a clean official link without `utm` or other tracking parameters; verify it is reachable before submitting
- Keep descriptions objective; avoid unverifiable promotional claims
- `id` must be a UUID not already used in the catalog
- `category` should reuse existing category names where possible (Chinese names as listed in the links above)
- For open-source projects set `"kind": "project"` and use project-side categories (Agent 技能 / CLI 工具 / 插件与扩展 / 代理应用 / MCP 服务 / 开发库); stars, language and license are fetched from the GitHub API at build time, no need to include them
- Hosted or closed-source MCP services belong on the tool side under the tool-side `MCP 服务` category (no `kind` field), not in the open-source project section
- Run `jq empty data.json` before submitting to confirm valid JSON
